- CSS란 무엇인가
  - **HTML이 만든 구조에 시각적 디자인을 입혀 사용자 경험을 개선**
  - 캐스케이딩
    - CSS에 ‘C’는 Cascading(계단식, 종속)을 의미한다.
    - 여러 스타일 규칙이 동일한 요소에 적용될 때 어떤 규칙이 최종적으로 적용될지를 결정하는 우선순위 매커니즘을 뜻한다.
- CSS 선택자와 선택자의 우선순위
  - CSS 선택자
    - HTML 요소 가운데 무엇을 스타일링 할지 알려주는 역할
  - 선택자의 우선순위
    - 누가 더 구체적인가를 따짐
      - !important > 인라인 스타일 > ID 선택자 > 클래스, 특성, 가상 클래스 선택자 > 요소, 가상 요소 선택자
- 가상 클래스와 가상 요소의 차이점
  | **구분**      | **가상클래스**          | **가사 요소**                    |
  | ------------- | ----------------------- | -------------------------------- |
  | **목적**      | 요소의 특정 상태를 선택 | 요소의 특정 부분을 만들거나 선택 |
  | **대상**      | HTML에 존재하는 요소    | HTML에 존재하지 않는 가상의 부분 |
  | **핵심 질문** | 어떤 상태인가?          | 어떤 부분을 꾸밀까?              |
  | **문법**      | 단일 콜론(:)            | 이중 콜론(::) (권장 사항)        |
  - 가상 클래스 - 요소가 지금 어떤 상태인가
    - **특정 상태(state)에 있는 요소를 선택하기 위해 사용된다.**
      - `:hover`: 이 요소 위에 마우스 커서가 올라와 있는 상태인가?
      - `:focus`: 사용자가 이 입력을 클릭해서 활성화된 상태인가?
    - 이미 존재하는 요소를 선택하고, 그 요소가 특별한 상태일 때만 스타일을 적용한다.
  - 가상 요소 - 요소의 특정 부분을 어떻게 꾸밀 것인가
    - **요소의 특정 부분(part)을 스타일링하기 위해 사용된다.**
      - `::before`: 요소의 내용 ‘앞' 이라는 가상의 부분을 만들어 스타일을 적용
      - `::selection`: 사용자가 마우스로 드래그하여 선택한 부분에 스타일을 적용
- `img` 태그와 CSS background-image 속성은 각각 언제 사용해야 하나
  - `img` 태그는 HTML 요소로, 페이지 구조에 포함되는 의미 있는 핵심 콘텐츠로 취급된다.
    - alt에 적힌 텍스트를 스크린 리더가 읽어준다.
    - 검색 엔진 최적화에 직접적인 영향을 준다.
  - `background-image` 속성은 장식이다.
    - 이미지가 콘텐츠와 직접적인 관련이 없는 장식용으로 사용된다.
    - CSS 속성이므로 이미지 제어력이 뛰어나다.
- 박스 모델이란
  - HTML 요소는 4개의 층으로 구성된 박스이다.
    - 중앙부터 content → padding → border → margin
  - 브라우저의 기본 박스 모델은 `content-box`로 되어있다.
    - `width` 속성은 콘텐츠 영역의 너비만 의미해서 패딩이나 테두리를 추가하면 박스의 전체 크기가 의도했던 것보다 커진다.
  - `box-sizing` 속성은 콘텐츠 + 패딩 + 테두리를 모두 포함해서 계산한다. (margin 제외)
  ```css
  html {
    box-sizing: border-box;
  }
  // 모든 요소와 ::before, ::after 가상 요소까지
  // 부모의 box-sizing값을 상속받도록 함
  *,
  *::before,
  *::after {
    box-sizing: inherit;
  }
  ```
- 전처리기란
  - CSS 전처리기는 CSS가 브라우저에 전달되기 전에 변수, 함수, 연산 등 프로그래밍적 기능을 사용할 수 있게 해주는 도구로, 작성한 코드를 컴파일하여 표준 CSS로 변환한다.
    - 변수, 중첩, 믹스인
- display: none, visibility: hidden, opacity: 0
  | **구분**      | display: none | visibility: hidden | opacity: 0       |
  | ------------- | ------------- | ------------------ | ---------------- |
  | 레이아웃 공간 | 사라짐(O)     | 유지(X)            | 유지(X)          |
  | 렌더링        | 렌더링 안 함  | 렌더링함(안 보임)  | 렌더링함(투명함) |
  | 이벤트 발생   | 불가능(X)     | 불가능(X)          | 가능(O)          |
  | 리플로 발생   | 발생함(O)     | 발생 안 함(X)      | 발생 안 함(X)    |
- z-index가 의도대로 동작하지 않을 경우 확인해야할 것
  - z-index는 `position` 속성이 `static` 이 아닌 요소에만 적용된다.
  - `z-index`가 예상대로 동작하지 않는 주된 이유는 부모나 조상 요소가 새로운 쌓임 컨텍스트를 형성했기 때문이다.
- 인라인과 블록 스타일 요소를 가운데 정렬하는 방법
  - 인라인 요소는 부모 블록 요소에 `text-align`을 적용하여
  - 블록요소는 고정된 `width`와 `margin:auto`를 사용해 수평 정력
  - Flex box는 인라인과 블록 요소 구분 없이 부모에 `display: flex`와 `justify-content`, `align-items`를 적용해 수평/수직 정렬을 구현
- `vertical-align`이 수직 정렬이 잘 안되는 이유
  - `vertical-align` 속성은 인라인, 인라인 블록, 테이블 셀에서만 적용된다.
  - `div` 와 같은 블록요소는 1줄 전체를 차지해서 동작을 안하고, `grid`나 `flex`를 사용해야 한다.
- 미디어 쿼리
  - 미디어 쿼리는 화면 크기에 따라 다른 CSS 스타일을 적용할 때 사용하며 반응형 웹 디자인의 핵심
- animation, transition, transform 속성
  - `transform`은 요소의 모양, 위치, 크기 등을 시각적으로 변형시키는 역할을 한다.
    - 문서의 흐름에 영향을 주지 않는다.
  - `transition`은 A를 B로 상태를 변화할 때 부드럽게 만드는 전환 효과를 제공한다.
    - `transform`과 함께 사용
  - `animation`은 `@keyframes`를 활용해 복잡하고 반복적인 움직임을 구현할 수 있다.
    - `transform`과 함께 사용
  - 성능 최적화를 위해 GPU 가속이 가능한 `transform`과 `opacity`를 활용하고 필요시 `will-change` 속성으로 브라우저 최적화를 유도할 수 있다.
- flex와 grid
  - Flex box는 1차원 한 방향으로 아이템을 유연하게 정렬하느 콘텐츠 중심 도구
  - Grid는 가로와 세로 2차원으로 레이아웃의 구조를 명시적으로 설계하는 레이아웃 중심 도구
- BEM(Block Element Modifier) 이란?
  - 클래스 이름을 명확하게 정의하여 CSS의 예측 가능성과 재사용성을 극대화하는 것을 목표
    - Blcok
      - 독립적인 구성요소, 재사용 가능한 컴포넌트 단위
      - header, menu, button, card, search-card
    - Element
      - 블록의 부분, 블록 없이는 의미를 가지지 못하는 종속단위
      - card**image, card**title, menu\_\_item
      - 블록과 요소 사이에 언더스코어 2개(\_\_)를 사용하여 지정
    - Modifier
      - 블록이나 요소의 모양, 상태, 동작을 변경하는데 사용
      - button—primary, button—disabled, menu—active, card—large
      - 이름과 수정자 이름 사이에 하이픈 2개(—)를 사용
- `@supports` 규칙은 언제 사용하나?
  - 특정 CSS 속성이나 함수를 브라우저가 지원하는지 확인한다.
  - 벤더 프리픽스(-webkit-, -moz-) 없이도 조건부 스타일 적용이 가능하다
- `.is()`와 `:where()` 가상 클래스 선택자의 차이점
  - 기능: 여러 개의 CSS 선택자를 하나로 묶어 중복을 줄여주는 가상 클래스 함수
  - 차이: 문법과 패턴 매칭은 동일하지만, 명시도를 다루는 방식에서 차이가 있다.
  | 구분            | `:is()`                                                              | `:where()`                                   |
  | --------------- | -------------------------------------------------------------------- | -------------------------------------------- |
  | 명시도 계산     | 괄호 안 인자 중 **가장 명시도가 높은 선택자**의 명시도를 그대로 취함 | 항상 명시도가 **0**                          |
  | 덮어쓰기 용이성 | 덮어쓰려면 동등하거나 높은 선택자 필요                               | 매우 쉽게 덮어쓰기 가능                      |
  | 주요 활용처     | 긴 선택자 그룹화, 일반 컴포넌트 스타일링                             | **CSS 리셋**, 기본 디자인 시스템/베이스 테마 |
