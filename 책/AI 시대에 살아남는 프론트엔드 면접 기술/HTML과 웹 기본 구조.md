- HTML
  - **웹의 구조를 담당**
  - 역할: 정보의 구조화 & 의미를 표시하는 것
  - 시맨틱 태크: 태그의 이름만으로 해당 영역의 역할을 알 수 있게 해준다.
    - 개발자, 검색 엔진, 스크린 리더와 같은 기기도 웹 사이트의 구조를 정확히 이해할 수 있다.
    - 검색 엔진 최적화, 웹 접근성을 높이는데 중요한 요소이다.
- HTML의 Doctype
  - **웹 브라우저가 문서를 어떤 버전으로 해석해야 하는지 알려 주는 선언문**
    - 표준 모드: 웹 표준을 최대한 정확하게 준수하여 렌더링
    - 쿼크 모드: 현재의 표준을 따르지 않는 웹 사이트가 최신 웹 브라우저에서도 깨져 보이지 않도록 지원하는 하위 호환성 렌더링 모드 (Doctype이 선언되지 않거나 잘못 선언 되었을 때)
- head 태그안에서 사용하는 태그
    - **head 태그는 웹 브라우저에 문서의 특징, 필요한 파일, 해석 기준을 알려주는 설명서로, 웹 사이트의 메타데이터를 담는 공간이다.**
    - title 태그: 웹 사이트의 제목을 정의
    - meta 태그: 다양한 정보를 담을 수 있는 만능 태그로, 웹 브라우저나 검색 엔진이 웹 사이트를 어떻게 이해할지 결정된다. 대표적인 속성으로는 `viewport`, `description`, `og` 등이 있다.
    - link 태그: css 파일, 파비콘 등 외부에서 가져와 연결해야 하는 요소는 link 태그를 사용한다.
    - style 태그: HTML 문서 안에서 CSS 코드를 직접 작성할 때
    - script 태그: 자바스크립트 연결할 때. `src` 속성을 지정하면 HTML 문서와 외부 파일을 연결할 수 있다.
- 시맨틱 태그의 역할
  - 검색 엔진 최적화
    - 검색 엔진의 크롤러가 명확한 태그로 설계된 구조를 더 정확히 이해한다.
  - 웹 접근성 향상
  - 코드의 가독성과 유지보수 효율 향상
- 웹 표준
  - **브라우저와 환경에 상관없이 동일하게 동작하는 웹을 만들기 위한 공식 규약**
- 웹 접근성
  - **장애 유무나 환경에 관계없이 모든 사용자가 동등하게 웹을 이용할 수 있도록 보장하는 철학**
  - 대체 텍스트 제공, 키보드 접근성, 색상 대비 확보
- `data-*` 속성
  - **`data-*` 속성은 HTML과 JS가 서로 데이터를 주고 받기 위해 약속된 표준 통로이다.**
  - `data-` 뒤에 케밥 케이스로 이름을 붙히고 `dataset` 을 JS에서 활용해 카멜 케이스로 접근하고 수정할 수 있다.
- 쿠키, 로컬스토리지, 세션 스토리지
  - 3개 모두 키-값(key-value)로 저장
  - 단일 문자열로만 저장됨
    - object나 array를 저장하려면 JSON을 이용하여 문자열로 변환,
  | 구분          | 쿠키 (Cookie)                                            | 로컬 스토리지 (LocalStorage)                       | 세션 스토리지 (SessionStorage)             |
  | ------------- | -------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------ |
  | **저장 용량** | 약 **4KB** (매우 작음)                                   | 약 **5MB~10MB** (큼)                               | 약 **5MB** (큼)                            |
  | **유효 기간** | 만료일/시간 설정 가능*(미설정 시 브라우저 종료 시 삭제)* | **영구적\***(직접 삭제 전까지 유지)\*              | **탭/창을 닫을 때까지**                    |
  | **서버 전송** | **매 HTTP 요청마다 헤더에 자동 포함**                    | 서버로 자동 전송되지 않음                          | 서버로 자동 전송되지 않음                  |
  | **접근 범위** | 동일 도메인 전체                                         | 동일 도메인 (Same Origin) 전체                     | **현재 열려 있는 탭/창 전용**              |
  | **주요 용도** | • 로그인 Session ID • 팝업 '오늘 하루 안 보기'           | • 사용자 환경 설정(다크모드 등) • 자동 로그인 상태 | • 일회성 입력 폼 데이터 • 스크롤 위치 복원 |
- 인덱스드 DB, 캐시 API
  - 인덱스드 DB
    - 대용량 구조화 데이터를 위한 웹 브라우저 안의 데이터베이스 (비동기식, NoSQL)
    - 복잡한 쿼리를 사용할 수 있다.
    - 오프라인 앱에 필수적
  - 캐시 API
    - 서비스워커와 함께 사용되어 네트워크 요청과 응답을 저장함으로써 성능을 향상시킨다.
    - 오프라인 환경에서도 웹 페이지를 사용할 수 있도록 돕는다.
- a 태그의 `rel`
  - **`rel` 속성은 링크된 문서와 현재 문서 사이의 관계(relationship)을 나타내는 속성이다.**
  - 외부 웹 사이트 링크를 새 탭에서 열때는 반드시 `rel` 속성을 추가해야 한다.
    - `noopener` : 새로 열린 탭이 기존 탭의 `window` 객체에 접근하는 것을 막는다.
    - `noreferrer` : 열림 탭으로 이동할 때 이전 웹 사이트의 주소 정보를 보내지 않아 사용자의 프라이버시를 보호한다.
- iframe 태그의 장점과 단점
    - **HTML 문서 안에 또 다른 HTML 문서를 삽입**
    - iframe 태그의 장점과 단점
        - 장점
            - 간편한 외부 콘텐츠 삽입
            - 비동기 로딩
            - 보안격리: iframe 태그의 내부 문서와 부모 문서는 서로의 돔에 직접 접근할 수 없다.
        - 단점
            - 성능저하: 독립적인 브라우저 컨텍스트를 생성
            - 검색 엔진 최적화의 어려움
            - 보안 취약점: 인터페이스를 겹쳐 속이는 매개체(클릭재킹)로 악용될 수 있다. - 삽입 정책을 제어하는 X-Frame-Options를 사용해서 제어할 수 있다.
    - iframe 이전에 외부 콘텐츠를 포함하는 방식
        - embed
            - 플래시나 PDF 뷰어 같은 브라우저 플러그인 기반 콘텐츠 삽입
            - 표준성과 확장성 면에서 한계
        - object
            - 오디오, 비디오, PDF, 다른 HTML 문서 등 다양한 종류의 외부 객체 삽입
- 헤딩 태그
  - **HTML 문서의 제목과 섹션 구조를 정의하는 태그이다.**
  - 논리적인 계층 구조가 만들어져 콘텍츠 분석과 검색 결과 노출에 도움이 된다.
  - 헤딩 태그의 사용 규칙
    - 제목 레벨을 건너뛰면 안된다.
      - ‘1장’ 다음 ‘1.1.1절’이 나오는 것처럼 구조가 어색해진다.
    - h1 태그는 한번만 사용해야한다.
        - 하나의 웹페이지에는 하나의 h1 태그만 사용해야한다.
        - 문서 전체를 대표하는 제목이어서 여러 번 사용하면 검색 엔진 최적화와 웹 접근성 측면에서 문제가 생긴다.
- HTML 엔티티란
  - 꺾쇠 괄호처럼 HTML에서 특별한 의미를 가지는 예약어, 키보드로 입력하기 어려운 특수 문자를 웹 브라우저에 출력할 때 사용하는 약속된 코드이다.
- img 태그의 `srcset`속성이란
  - **사용자 환경에 가장 적합한 이미지를 웹 브라우저가 자동으로 선택해 표시하도록 지시하는 역할**
  - src는 srcset을 지원하지 않은 구형 브라우저를 위한 대체 이미지로 사용된다.
- canvas 태그란
  - **HTML문서 안에 그림을 그릴 수 있는 영역을 만드는 태그**
    - 동적인 그래픽 처리
  - 특징
    - JS 기반 드로잉
    - 비트맵 방식으로 동작 - 독립된 객체가 전체 그림의 일부 픽셀로 합쳐진다. 수정하려면 해당 부분을 지우고 다시 그려야 한다.
    - 다양한 활용성 - 단순 도형, 그래프, 실시간 영상 처리 등
- svg 태그는 어떤 용도로 사용하나요?
  - **벡터 그래픽을 HTML 문서 안에서 정의하기 위한 컨테이너**
  - 비트맵과 백터
    - 비트맵 이미지
      - JPG, PNG, GIF 파일이 비트맵 이미지에 속함
      - 이미지를 수많은 작은 점(픽셀)의 집합으로 저장
    - 벡터 이미지
      - 점, 선, 면의 수학적 정보를 기반으로 이미지를 표현
